# NodeThemes Image Optimizer

**Free WebP image optimizer plugin for WordPress.**

NodeThemes Image Optimizer is a free WordPress plugin that converts JPEG and PNG images to lightweight WebP with one click from your Media Library, entirely on your own server. No API keys and no third-party service.

- Website: [NodeThemes Image Optimizer on nodethemes.com](https://nodethemes.com/product/nodethemes-image-optimizer-pro/)
- All free plugins: [Free WordPress plugins from NodeThemes](https://nodethemes.com/free-plugins/)

## Features (free version)

- One-click WebP conversion from the Media Library (JPEG and PNG), up to 50 images
- Originals are kept; WebP copies are served automatically on your public pages
- Adjustable WebP quality (10-100)
- Savings shown for every image
- Works with GD (WebP) or Imagick

## NodeThemes Image Optimizer Pro

The free plugin is complete on its own. The Pro add-on, sold at [nodethemes.com](https://nodethemes.com/product/nodethemes-image-optimizer-pro/) as a yearly license with updates and support, adds:

- Unlimited images
- Automatic optimisation of every new upload
- Bulk optimizer with live progress
- Replace mode (WebP replaces the original)
- Maximum width, height and file size per image

Pro is installed next to the free plugin; your settings and data stay when you upgrade. See the full **Free vs Pro** comparison table on the [product page](https://nodethemes.com/product/nodethemes-image-optimizer-pro/).

## Installation

1. Download the latest version from [nodethemes.com/free-plugins](https://nodethemes.com/free-plugins/) or from the **Releases** of this repository.
2. In WordPress go to **Plugins → Add New Plugin → Upload Plugin**, choose the zip and click **Install Now**, then **Activate**.
3. New versions then appear in **Dashboard → Updates** like any other plugin.

Requirements: see the plugin header and `readme.txt`.
